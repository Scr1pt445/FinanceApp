# 0001. UI на WPF

Дата: 2026-10-15 · Статус: принято

## Контекст
Приложение только для Windows-ПК. Ключевые сценарии — иконка в трее, глобальная горячая клавиша (`RegisterHotKey`) и окно быстрого ввода, которое появляется быстрее 300 мс. Рассматривались WPF и Avalonia.

## Решение
WPF + MVVM (CommunityToolkit.Mvvm).

## Последствия
- Зрелая экосистема для трея и Win32-интеропа, предсказуемое время показа заранее созданного окна.
- WPF чаще встречается в .NET-вакансиях — это важно для портфолио.
- Кроссплатформенности нет. Чтобы её можно было добавить позже, домен, сценарии и инфраструктура не зависят от UI: WPF-проект — только тонкий слой поверх `FinanceApp.Application`.
