# 0004. Приложение самостоятельное, экспорт в Obsidian — опциональная интеграция

Дата: 2026-10-15 · Статус: принято

## Контекст
Изначально приложение задумывалось как источник данных для страницы «Финансы» в Obsidian. Но им могут пользоваться и другие люди, у которых Obsidian нет.

## Решение
- Приложение полноценно работает без Obsidian: собственные список операций, итоги, справочники.
- Экспорт CSV по контракту (см. [requirements.md, раздел 5](../requirements.md)) — **интеграция**, которая включается в настройках и по умолчанию выключена. Путь к файлу задаёт пользователь; в коде и репозитории личные пути не хранятся.
- Экспорт подписан на изменения данных и выполняется в фоне. Ошибка записи (файл занят) повторяется и показывается как статус, но не ломает ввод операции.

## Последствия
Ядро не знает про Obsidian: оно публикует событие «данные изменились», а интеграция на него реагирует. По тому же принципу можно добавить другие выгрузки.
