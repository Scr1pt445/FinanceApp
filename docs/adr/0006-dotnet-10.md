# 0006. .NET 10 вместо .NET 8

Дата: 2026-10-15 · Статус: принято

## Контекст
В требованиях указан .NET 8. Поддержка .NET 8 заканчивается в ноябре 2026 года. .NET 10 — текущий LTS-выпуск (поддержка до ноября 2028), его SDK уже установлен.

## Решение
Все проекты нацелены на `net10.0` (WPF-проект — `net10.0-windows`).

## Последствия
Доступны актуальные C# 14, EF Core 10 и формат решения `.slnx`. Для запуска нужен .NET 10 Runtime (или self-contained-публикация).
