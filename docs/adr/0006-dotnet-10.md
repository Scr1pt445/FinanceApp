# 0006. Target .NET 10 instead of .NET 8

Date: 2026-10-15 · Status: Accepted

## Context

The initial draft named .NET 8. .NET 8 support ends in November 2026. .NET 10 is the current LTS release (supported until November 2028).

## Decision

All projects target `net10.0` (the WPF project will target `net10.0-windows`). The SDK is pinned in `global.json`.

## Consequences

C# 14, EF Core 10 and the `.slnx` solution format are available. Running the app requires the .NET 10 runtime or a self-contained publish.
