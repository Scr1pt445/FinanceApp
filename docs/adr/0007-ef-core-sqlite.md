# 0007. EF Core + SQLite, деньги — `decimal`

Дата: 2026-10-15 · Статус: принято

## Контекст
Нужна локальная БД без сервера. Деньги нельзя хранить в `double`. В SQLite нет десятичного типа: EF Core хранит `decimal` как `TEXT` и не умеет переводить в SQL агрегаты по таким колонкам.

## Решение
- SQLite + EF Core (миграции, LINQ, `DateOnly` из коробки). Схема обновляется миграциями при запуске.
- Все суммы и курсы — `decimal` в коде и `TEXT` в БД, без потери точности.
- Итоги считаются в памяти по операциям нужного периода (`SummaryCalculator`), а не в SQL. У личных финансов это тысячи строк — это быстро и легко тестировать.

## Последствия
Нельзя сортировать и фильтровать по сумме в SQL — это и не требуется. Если объёмы вырастут, суммы можно перевести в целые копейки (`INTEGER`) конвертером значений без изменения домена.
